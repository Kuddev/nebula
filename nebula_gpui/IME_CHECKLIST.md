# G2 闸门：IME 中文输入人工验收清单

环境：`nebula-gpui.exe`（或 `NEBULA_GPUI_SHELL=1` 的进程内形态），
微软拼音输入法。任一项失败即 G2 否决：记 issue + 截图，修复后整单重验。

## 终端区

- [ ] 输入拼音：预编辑串显示在光标单元格处，带下划线，不写进终端。
- [ ] 候选窗紧贴光标单元格（不在屏幕角落或窗口原点）。
- [ ] 空格/数字选字提交：汉字一次上屏，预编辑消失，无重复字符。
- [ ] Esc 取消组合：预编辑消失，终端不收到任何泄漏字符。
- [ ] 组合中退格：逐音节删除，不破坏已上屏内容。
- [ ] 组合期间终端有滚动输出（如 `ping -t`）：预编辑跟随光标不错位。
- [ ] 长句连打（20+ 字）：不丢字、不乱序。
- [ ] 中英标点切换、全角/半角切换正常。
- [ ] vim/TUI 内插入模式输入中文：候选窗锚点跟随 TUI 光标。
- [ ] 输入法开关切换（Ctrl+Space / Win+Space / Shift）：无按键泄漏进终端。
- [ ] 宽字符光标：光标停在汉字上时为两格宽（块/下划线形态都验）。
- [ ] 提交后立即敲 ASCII：无输入模式残留。

## 窗口/焦点交互

- [ ] 组合中切走窗口焦点再切回：预编辑状态不残留、不重复上屏。
- [ ] 多 tab 切换后 IME 仍绑定当前活动终端。
- [ ] DPI 缩放（跨显示器拖动）后候选窗位置仍正确。
