# Nebula Terminal 1.2.0

Nebula Terminal 1.2.0 expands the Runtime control surface, adds horizontal title-bar tabs and SVN support, and concentrates this cycle's Windows, WSL, SSH, IME, and GPUI reliability work into one release.

Nebula Terminal 1.2.0 扩展了 Runtime 控制能力，加入水平标题栏标签页与 SVN 支持，并集中交付本周期的 Windows、WSL、SSH、输入法与 GPUI 稳定性改进。

## English

### Highlights

- Horizontal title-bar tabs support selection, drag reordering, docking, split creation, and horizontal auto-scroll. In top mode, Settings now lives in the three-dot menu and the first tab starts exactly at the terminal/powerline left edge; sidebar mode is unchanged.
- The Runtime can orchestrate typed workflows, control named agents and processes, report real exit status and pane lifecycle events, and create transactional managed-agent worktrees.
- Completion and file-tree work now follow each pane's real local, WSL, or SSH filesystem context.
- This release addresses the resident second-launch, Sogou IME, WSL default-shell, and conditional Ctrl+C Copy reports tracked in Issues #39, #43, #44, and #48. The mapping below keeps those fixes traceable while the Issues remain open for user verification.

### Added

- Added `nebula ctl orchestrate`, a typed single-request workflow whose deterministic local steps are bounded by step count, byte ceiling, and readiness timeout, with per-workflow `stop`/`continue` failure behavior.
- Added named-agent control, process and control-key APIs, real command exit status, and pane lifecycle events to the Runtime contract.
- Added isolated, transactional worktree creation for managed agents, including stable branch/path identity and failure-aware rollback.
- Added the versioned Runtime schema, control API documentation, and `nebula-runtime` Skill to the ZIP and installer payloads.
- Added the horizontal title-bar tab layout with drag reorder, dock/split targets, and drag/selection auto-scroll.
- Added SVN working-copy detection and repository status/workflow support to the GPUI shell.
- Added a failure-only SSH Retry action immediately to the left of Close in both the legacy and GPUI shells. Retry atomically replaces only the failed pane with the same destination.

### Fixed

- Fixed a second Nebula launch silently disappearing while a resident instance was running. The launch request is now handed to that instance, which creates and focuses the requested tab/window. Addresses [#39](https://github.com/Kuddev/nebula/issues/39).
- Fixed unmodified letters and Space bypassing the Windows text-input path, allowing Sogou and other IMEs to confirm composition normally. Addresses [#43](https://github.com/Kuddev/nebula/issues/43).
- Fixed WSL launches forcing Bash instead of honoring the guest account's `/etc/passwd` default shell. Addresses [#44](https://github.com/Kuddev/nebula/issues/44).
- Fixed Ctrl+C Copy consuming the key when there is no selection and repeatedly copying a stale selection. No selection now propagates Ctrl+C to the PTY; an explicit copy clears selection before the next key event. Addresses [#48](https://github.com/Kuddev/nebula/issues/48).
- Fixed legacy `user@host:port` SSH destinations failing the Windows `ssh -G` configuration probe with resolver error `11001`. Only the probe target is normalized to `ssh://user@host:port`; the real connection destination is unchanged.
- Fixed Codex treating Shift+Enter as ordinary Enter by enabling ConPTY Win32 input, tracking DECSET 9001, and encoding the corresponding Win32 key record.
- Fixed runtime background-blur toggling and the related path that could leave a window hidden after tray support was disabled.
- Fixed opacity sliders rebuilding fonts, terminal palettes, themes, wallpaper textures, and DWM state on every drag event.
- Fixed WSL cold-start/timeout failures being rendered as empty directories. The Files panel now keeps following the active local/WSL/SSH pane after tab changes, pane changes, and manual navigation.
- Fixed PowerShell sessions opened from the three-dot menu or with Powerline disabled missing OSC command state before their first interaction.
- Fixed alternate PowerShell profile launches missing Nebula command completion.
- Fixed checked-in bash, fish, and zsh completion scripts omitting `ctl orchestrate`, `--gpui`, and `--legacy-shell`.
- Fixed the installer's fallback and numeric file-version metadata lagging behind the application version.

### Improved

- Routed completion requests through each pane's own local, WSL, or SSH filesystem provider.
- Batched WSL file-tree starting points into one guest `find` call, increased the cold-start budget, and replaced the four-second polling scan with event-driven refreshes.
- Selected shell injection by shell family: PowerShell keeps its full integration, cmd uses its compatible minimal status path, Nushell keeps native completion, and other shells use the supported OSC fallback.
- Stabilized Runtime transport/discovery and kept pane/window ownership explicit across the agent-control path.
- Improved mixed-DPI dragging by separating native move handling from the final DPI/size commit and coalescing intermediate work.
- Matched split-pane chrome and title-bar integration in GPUI, moved only top-mode Settings into the three-dot menu, and preserved the sidebar-mode Settings button.
- Removed the shell-injected `fmt` action and aligned the expanded sidebar toggle with the legacy shell's softer selected surface.
- Restored the README Star History chart through [#49](https://github.com/Kuddev/nebula/pull/49).

## 中文

### 重点更新

- 水平标题栏标签页支持选择、拖拽排序、停靠、创建分屏与水平自动滚动。顶部模式的设置入口已收进三个点菜单，首个标签与终端/powerline 左边缘严格对齐；侧边栏模式不变。
- Runtime 新增强类型工作流编排、命名 agent/进程控制、真实退出码、pane 生命周期事件与事务式托管 agent worktree。
- 补全与文件树会跟随每个 pane 的真实本地、WSL 或 SSH 文件系统上下文。
- 本版处理了 Issue #39、#43、#44、#48 对应的驻留进程二次启动、搜狗输入法、WSL 默认 shell 与条件式 Ctrl+C 复制问题。下方保留明确定位，Issue 暂不自动关闭，等待用户实机验证。

### 新增

- 新增 `nebula ctl orchestrate` 强类型单请求工作流：本地确定性步骤受步数、字节上限与就绪超时约束，并支持按工作流配置 `stop`/`continue` 失败行为。
- Runtime 契约新增命名 agent 控制、进程/控制键 API、真实命令退出码与 pane 生命周期事件。
- 新增隔离、事务式的托管 agent worktree 创建，保留稳定的分支/路径身份，并按可确认的失败边界回滚。
- ZIP 与安装器新增带版本的 Runtime schema、控制 API 文档和 `nebula-runtime` Skill。
- 新增水平标题栏标签布局，以及拖拽排序、停靠/分屏目标和拖拽/选择自动滚动。
- GPUI 界面新增 SVN 工作副本识别、仓库状态与操作工作流。
- 旧界面和 GPUI 界面都新增仅在 SSH 连接失败后出现的“重试”按钮，位置紧邻“关闭”左侧；重试只会在原位原子替换失败的 pane。

### 修复

- 修复已有驻留实例时第二次启动 Nebula 会静默消失的问题。启动请求现在会交给驻留实例，由它创建并聚焦所需标签/窗口。对应 [#39](https://github.com/Kuddev/nebula/issues/39)。
- 修复普通字母与空格绕过 Windows text-input 路径的问题，搜狗等输入法现在可以正常确认组合文本。对应 [#43](https://github.com/Kuddev/nebula/issues/43)。
- 修复 WSL 启动时强制使用 Bash、忽略来宾账号 `/etc/passwd` 默认 shell 的问题。对应 [#44](https://github.com/Kuddev/nebula/issues/44)。
- 修复没有选区时 Ctrl+C 被复制动作吞掉，以及旧选区导致反复复制的问题。无选区时 Ctrl+C 会传给 PTY；明确复制后会在下一个按键事件前清除选区。对应 [#48](https://github.com/Kuddev/nebula/issues/48)。
- 修复旧格式 `user@host:port` 让 Windows `ssh -G` 配置探测报解析错误 `11001`。只有探测目标会规范化为 `ssh://user@host:port`，实际连接目标保持不变。
- 修复 Codex 把 Shift+Enter 当作普通 Enter：启用 ConPTY Win32 输入、跟踪 DECSET 9001，并编码相应的 Win32 按键记录。
- 修复运行时背景模糊开关无效，以及关闭托盘后窗口可能继续隐藏的同源问题。
- 修复不透明度滑块每次拖动事件都重建字体、终端色表、主题、壁纸纹理与 DWM 状态的问题。
- 修复 WSL 冷启动/超时被渲染成空目录的问题；切换标签、pane 或手动导航后，Files 面板会继续跟随当前本地/WSL/SSH pane。
- 修复从三个点菜单启动或关闭 Powerline 的 PowerShell 在第一次交互前缺少 OSC 命令状态的问题。
- 修复备用 PowerShell profile 启动路径缺少 Nebula 命令补全的问题。
- 修复签入的 bash、fish、zsh 补全脚本缺少 `ctl orchestrate`、`--gpui` 与 `--legacy-shell` 的问题。
- 修复安装器兜底版本与数字文件版本没有跟随应用版本的问题。

### 改进

- 补全请求现在通过每个 pane 自己的本地、WSL 或 SSH 文件系统提供器执行。
- WSL 文件树会把多个起点合并成一次来宾 `find`，延长冷启动预算，并以事件驱动刷新代替每四秒轮询扫描。
- 按 shell 家族选择注入：PowerShell 保留完整集成，cmd 使用兼容的最小状态路径，Nushell 保留原生补全，其他 shell 使用受支持的 OSC fallback。
- 稳定 Runtime 传输与发现逻辑，并在 agent 控制路径中明确维护 pane/window 所属关系。
- 改进混合 DPI 拖动：原生移动处理与最终 DPI/尺寸提交分离，中间更新合并执行。
- 对齐 GPUI 分屏边框与标题栏整合；只移动顶部模式的设置入口，侧边栏模式设置按钮保持不变。
- 移除 shell 注入的 `fmt` 动作，展开的侧栏切换按钮改用旧界面更柔和的选中色。
- 通过 [#49](https://github.com/Kuddev/nebula/pull/49) 恢复 README Star History 图表。
