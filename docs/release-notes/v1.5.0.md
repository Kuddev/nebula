# Nebula Terminal 1.5.0

## English

### Added

- Added an SSH remote-file workspace with separate username and host fields, recent and OpenSSH-config usernames, navigation, upload/download, remote copy/paste, transfer conflicts, progress, and cancellation.
- Added a compact saved-command manager and a repository-aware `Add to .gitignore` action.
- Added a Git history view with smooth branch tracks, correctly classified refs, and a three-column conflict-resolution tab that writes and stages the result.
- Added indexed filename search to the Files drawer with case, whole-word, and regex controls. Addresses [#88](https://github.com/Kuddev/nebula/issues/88) for the search-box portion; the requested `Ctrl+F` shortcut remains open.
- Added a persistent option to skip risky multi-line paste confirmation. Contributed by [@Sakyvo](https://github.com/Sakyvo) in [#76](https://github.com/Kuddev/nebula/pull/76).
- Added an option to hide tab close buttons in both tab layouts while keeping middle-click close. Contributed by [@Sakyvo](https://github.com/Sakyvo) in [#77](https://github.com/Kuddev/nebula/pull/77).

### Fixed

- Fixed GPUI text inputs sending `Ctrl+V` to the terminal behind them, and kept the saved-command manager compact when it contains only a few rows.
- Fixed tab switches reloading SFTP and starting remote browsing before authentication completed; directory contents, selection, scroll position, and confirmed locations now remain stable.
- Fixed duplicate SSH password prompts and stopped reusing failed pooled transports; the affected channel retries once on a fresh connection without terminating unrelated panes. Addresses [#50](https://github.com/Kuddev/nebula/issues/50) for post-failure reconnect only; the intermittent disconnect and rendering reports remain open.
- Fixed TortoiseSVN dialogs failing to open with `ERROR_INVALID_HANDLE` (`os error 6`) when Nebula has no inheritable console handles.
- Fixed WSL Agent activity tracking for direct, wrapped, and broadcast commands, and cleared stale activity when control returns to the guest shell.

### Improved

- Made SFTP publication transactional and improved throughput with bounded concurrency, pipelined writes, segmented reads, atomic downloads, recoverable replacement, and cancellation-safe cleanup.
- Made GPUI the default product shell and kept the legacy shell behind an explicit feature, reducing ordinary release builds to the product path.

## 中文

### 新增

- 新增 SSH 远程文件工作区：分离用户名与主机字段，提供最近使用和 OpenSSH config 用户名，并支持导航、上传下载、远端复制粘贴、冲突处理、进度与取消。
- 新增紧凑的保存命令管理器，以及能够识别仓库根的“加入 `.gitignore`”操作。
- 新增带丝滑分支轨道和正确引用语义的 Git 历史视图，并提供会写回结果并暂存文件的三栏冲突解决 Tab。
- 文件抽屉新增带索引的文件名搜索，以及区分大小写、全词和正则选项。此项对应 [#88](https://github.com/Kuddev/nebula/issues/88) 的搜索框部分；需求中的 `Ctrl+F` 快捷键仍未完成。
- 新增永久跳过高风险多行粘贴确认的选项。由 [@Sakyvo](https://github.com/Sakyvo) 在 [#76](https://github.com/Kuddev/nebula/pull/76) 中贡献。
- 新增在两种标签布局中隐藏关闭按钮的选项，同时保留中键关闭。由 [@Sakyvo](https://github.com/Sakyvo) 在 [#77](https://github.com/Kuddev/nebula/pull/77) 中贡献。

### 修复

- 修复 GPUI 文本输入框把 `Ctrl+V` 发送到背后终端的问题，并让只有少量结果的保存命令管理器保持紧凑。
- 修复切换标签时重新加载 SFTP，以及认证完成前启动远程浏览的问题；目录内容、选中项、滚动位置和已确认位置现在会稳定保留。
- 修复 SSH 重复密码提示，并停止复用已经失效的连接；受影响的 channel 会在全新连接上重试一次，同时不终止其他 pane。此项对应 [#50](https://github.com/Kuddev/nebula/issues/50) 的失败后重连部分；间歇断连和渲染报告仍保持开放。
- 修复 Nebula 没有可继承控制台句柄时，TortoiseSVN 对话框因 `ERROR_INVALID_HANDLE`（`os error 6`）无法打开。
- 修复 WSL Agent 对直接命令、包装器命令和广播命令的活动跟踪，并在控制权回到来宾 shell 后清除过期状态。

### 改进

- SFTP 发布改为事务式流程，并通过有界并发、流水线写入、分段读取、原子下载、可恢复替换和取消安全清理提升吞吐与可靠性。
- 将 GPUI 设为默认产品壳，旧壳保留在显式 feature 后，普通 Release 构建只包含产品路径。
